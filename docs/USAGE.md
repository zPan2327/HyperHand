# HyperHand 使用说明

> English version: [USAGE_EN.md](USAGE_EN.md)
>
> 适用于 3.4.x 及之后的版本。技术细节（识别算法、Hook 点、参数全表）见 [README](../README.md)，
> 版本变更见 [CHANGELOG](../CHANGELOG.md)。

HyperHand 是面向小米手机（HyperOS / MIUI，Android 13 及以上）的 LSPosed 模块，提供三件事。
目前只在小米 14 / HyperOS 3（Android 16）上完整实测，其他机型与系统版本可能需要适配：

| 功能 | 一句话 |
|---|---|
| 单手模式增强 | 底部下滑的触发区更大、判定更宽容，进单手模式更容易 |
| 按键映射 | 把音量键的短按 / 长按 / 双击 / 连按映射成切歌、播放、调音量 |
| 桌面快捷菜单滑选 | 长按桌面图标后不松手，直接滑到菜单项上抬手选中 |

---

## 1. 安装与启用

1. 确认框架支持 **libxposed API 102**：Vector 2.x 或新版 LSPosed 才有；旧版 LSPosed 1.9.x 只到 101，会直接忽略本模块。
2. 安装 APK 后，在框架里**启用 HyperHand** 并勾选作用域：
   - `system`（系统框架 / `system_server`）：按键映射必需；
   - `com.android.systemui`（系统界面）：单手模式增强必需；
   - `com.miui.home`（小米桌面）：桌面快捷菜单滑选及手势互斥所需。

   当前 `staticScope=false`，作用域不会由模块自动强制勾选；不需要的功能可以不选对应作用域。
3. 让新代码注入：

   ```bash
   adb shell am crash com.android.systemui   # 重启系统界面
   adb shell am crash com.miui.home          # 重启桌面（滑选功能需要）
   ```

   没有 adb 也可以直接重启手机。

装好后打开 HyperHand，底部三个标签是「概览 / 设置 / 关于」。普通设置项会自动保存并即时生效；
按键规则需要在编辑页点「保存」。日常使用不需要 root，只有「重启作用域」需要 root 授权。

## 2. 单手模式增强

**怎么用**：在屏幕底部边缘往下滑，进入单手模式。

- 默认触发区是底部 **56dp**，比系统原生的 25dp 宽，拇指够得着的位置基本都在里面。
- 慢拉和快甩都认：慢滑要求「拉得够长 + 轨迹干净」，快甩看瞬时速度；两条路径各自算置信度。
- 从触发区**上方**往下拉，或者从顶部状态栏拉，仍然是通知中心 / 控制中心，模块会让位给原生。

**三种触发模式**（设置 → 触发模式）：

| 模式 | 手感 |
|---|---|
| 自然 | 速度与距离综合判定，默认值 |
| 灵敏 | 阈值更低，轻扫就能触发 |
| 防误触 | 阈值更高，优先保证底部区域能正常滚动页面 |

**退出单手模式**：点一下缩小区域的上方、在胶囊条上往上滑、或者等它超时 —— 全部是系统原生行为，模块没有改写。

**外观**：设置 →「模糊壁纸背景」可以把背景换成模糊壁纸并调半径与压暗；「调试 → 预览遮罩」能立刻进一次单手模式看效果。

## 3. 按键映射

**开启**：设置 →「按键映射」→ 打开总开关。

**建规则**：进「规则与按键」→「新建规则」：

1. **触发**：点「添加触发按键」，弹窗里选物理按键（音量加 / 音量减）和按压方式
   （短按 / 长按 / 双击 / 连按），确认后才添加。
2. **动作**：点「添加执行动作」，弹窗里选具体动作（上一首 / 下一首 / 播放 / 暂停 / 播放暂停 / 保持原功能）。
3. **条件**（可选）：加「应用正在播放」「屏幕锁定」这类状态条件，多条条件之间可选「且 / 或」。
4. 命名、调优先级、保存。

规则列表里每条规则右侧是总开关，**长按整行**会弹出菜单：复制 / 删除。删除会二次确认。

**验证**：保存后回桌面按音量键试。测长按要按住 500ms 以上
（`adb shell input keyevent --longpress` 在部分 ROM 只按 300ms，测不出来）。

**两个隐藏点**：

- 首页最底部那行 `HyperHand x.y.z · 按键映射` **连点 5 下**（间隔小于 0.8 秒）→ 打开「运行状态」，
  能看到 Hook 是否激活、规则条数、最近一次判定。
- 规则有未保存修改时直接退出，会问「放弃修改？」。

匹配优先级：同一按键的规则按「优先级」从高到低取第一条命中的；条件不满足就继续找下一条。

## 4. 桌面快捷菜单滑选

**怎么用**：在桌面长按图标 → 菜单弹出后**不要松手** → 把手指滑到目标菜单项上 → 抬手直接执行。

- 用的是系统原生长按菜单，模块只接管「手指移动」到「抬手」这一段，不改菜单本身。
- 角度阈值默认比较宽，斜着滑也能选中；不想用就在设置里关掉「启用长按滑选」。
- 改完需要重启桌面进程才生效（`adb shell am crash com.miui.home`）。

## 5. 其他设置

| 位置 | 作用 |
|---|---|
| 个性化 → 语言 | 跟随系统 / 简体中文（默认）/ 繁體中文 / English，切换后界面立即刷新 |
| 显示高级参数 | 展开识别阈值、触发区、外观与算法常量的完整参数 |
| 恢复默认参数 | 整体回到「自然」模式的推荐值；之前手动改过的显式值会一并清掉 |
| 重启作用域 | 重新注入钩子，需要 root 授权；可选系统框架、系统界面与桌面 |
| 关于 → 调试 | 看最近一次手势的位移 / 速度 / 置信度与未触发原因 |

## 6. 常见问题

**Q：装了但完全没反应？**
按顺序排查：① 框架是否支持 libxposed API 102；② 模块是否启用；③ 是否 `am crash` 重启过 SystemUI；
④ `adb logcat -s HyperHand` 能否看到 `attached to SystemUI`。

**Q：想触发单手模式，结果拉出了通知中心？**
多半是桌面进程没重启，闸门没生效。`adb shell am crash com.miui.home`。

**Q：慢滑也触发了 / 想要更难触发？**
换「防误触」模式，或把「显示高级参数」里的最小置信度调到 0.62~0.70、最小位移调到 16~22dp；
只想禁掉慢拉路径，把慢滑开关关掉。

**Q：音量键映射没生效？**
先看「运行状态」里 Hook 是否激活、规则条数对不对；再看规则的条件是否满足（例如「指定应用正在播放」但你当前的应用没在播）。

**Q：会不会影响上滑回桌面、最近任务、返回手势？**
不会。模块只观察不消费触摸事件，也不修改任何窗口的触摸区域。

更多问题见 [README 的「常见问题」](../README.md#常见问题)。

## 7. 恢复原状 / 卸载

- **临时停用**：关掉对应的功能总开关（单手模式 / 按键映射 / 快捷菜单滑选），立即恢复系统行为。
- **全部恢复**：设置 →「恢复默认参数」，或在框架里停用模块后重启手机。
- **卸载**：先在框架里停用模块，再卸载 APK；残留的 `Settings.Global` 键（前缀 `oh_tuner_`）不影响系统。
