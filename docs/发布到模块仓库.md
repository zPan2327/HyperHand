# 发布到 LSPosed 官方模块仓库

LSPosed / Vector 管理器里的"可下载模块列表"来自 GitHub 组织
[`Xposed-Modules-Repo`](https://github.com/Xposed-Modules-Repo)：一个模块一个仓库，
仓库里只放 release，不放源码。

## 收录要求

官方写在 [`Xposed-Modules-Repo/.github`](https://github.com/Xposed-Modules-Repo/.github) 里，四条硬性条件：

| # | 要求 | 本模块对应 |
|---|---|---|
| 1 | 仓库名 = 模块包名 | `com.hyperhand.tuner` |
| 2 | 仓库 description 非空，作为模块显示名 | `HyperHand` |
| 3 | 至少一个 release | 见下文 tag 规则 |
| 4 | release 至少有一个 `.apk` 资源，且 tag 必须是 `VersionCode-VersionName` | `20000-2.0.0` |

tag 里用短横线，不是 `v2.0.0`。机器人只会**修正**写错的 tag，不会替你补 APK；
而且"只编辑 release 资源、不改 release 内容"不会触发机器人，必须动一次 release 本身。

## 一次性准备

1. **提交仓库**

   打开 <https://modules.lsposed.org/submission>，用 GitHub 账号登录，填包名 `com.hyperhand.tuner`。
   机器人会在组织下建好同名仓库，并把你加成该仓库的 admin。

2. **配一个能写这个仓库的 token**

   GitHub → Settings → Developer settings → **Personal access tokens (classic)** →
   Generate new token，勾 `repo`（或细粒度 token 只给 `Xposed-Modules-Repo/com.hyperhand.tuner`
   的 `Contents: Read and write`）。

   然后在本仓库（源码仓库，不是模块仓库）→ Settings → Secrets and variables → Actions →
   New repository secret，名字填 `MODULE_REPO_TOKEN`，值粘贴 token。

   没配这个 secret 时，CI 的同步步骤会自动跳过，不影响本仓库的 Release。

## 每次发版

```bash
git tag -a v2.0.0 -m "v2.0.0"
git push origin v2.0.0
```

CI 会做三件事：

1. 构建 `module/out/HyperHand.apk`，并用 `aapt2 dump badging` 读出真实的 `versionCode` / `versionName`；
2. 在本仓库发 Release（tag `v2.0.0`，附 APK）；
3. 把同一个 APK 同步到 `Xposed-Modules-Repo/com.hyperhand.tuner`，
   tag 用 `版本号-版本名`（如 `20000-2.0.0`）。

对应的 workflow 片段：

```yaml
      - name: Publish to Xposed-Modules-Repo
        if: startsWith(github.ref, 'refs/tags/v') && env.MODULE_REPO_TOKEN != ''
        uses: softprops/action-gh-release@v2
        with:
          repository: Xposed-Modules-Repo/com.hyperhand.tuner
          token: ${{ env.MODULE_REPO_TOKEN }}
          tag_name: ${{ steps.apk.outputs.version_code }}-${{ steps.apk.outputs.version_name }}
          files: module/out/HyperHand.apk
```

## 校验

```bash
# 模块仓库里是否已经有这次发布
curl -s https://api.github.com/repos/Xposed-Modules-Repo/com.hyperhand.tuner/releases/latest \
  | grep -E '"(tag_name|name|browser_download_url)"'

# APK 里的版本号（应与 tag 前段一致）
aapt2 dump badging module/out/HyperHand.apk | head -1
```

## 排错

| 现象 | 原因 |
|---|---|
| 管理器里搜不到模块 | 模块仓库的 latest release 还没有 APK，或 tag 不是 `版本号-版本名` |
| 同步步骤被跳过 | 没配 `MODULE_REPO_TOKEN`，或 token 对该仓库没有写权限 |
| 同步报 404 | 仓库还没通过 <https://modules.lsposed.org/submission> 创建出来 |
| 管理器里模块显示"需要更新的框架" | 框架实现低于 API 102（`module.prop` 里 `minApiVersion=102`）；换 Vector 2.x / 新版 LSPosed |
| 模块启用后不生效 | 静态作用域只有 `com.android.systemui` + `com.miui.home`，改钩别的进程需要先改 `scope.list` 再发版 |
