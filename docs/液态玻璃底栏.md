# 液态玻璃底栏

底栏是 Compose 画的（`:glass` 模块），渲染实现整体来自
[LiquidDemo](https://github.com/zPan2327/LiquidDemo)，而后者复刻自
[compose-miuix-ui/miuix](https://github.com/compose-miuix-ui/miuix) 与
[Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass)（均为 Apache-2.0）。

这一页只记两件事：**它挂在这套 Java 工程里的结构**，以及**迁移过程中踩到的坑和改法**。
组件本身的设计原理见 LiquidDemo 的 [docs/FAQ.md](https://github.com/zPan2327/LiquidDemo/blob/main/docs/FAQ.md)。

---

## 结构

```
glass/src/main/kotlin/
├── io/github/zpan2327/liquidglass/      渲染实现（7 个文件，从 LiquidDemo 逐字迁入）
│   ├── LiquidGlassNavigationBar.kt      底栏本体
│   ├── Lens.kt / Vibrancy.kt            折射 AGSL / 增艳
│   ├── InteractiveHighlight.kt          按下的白色叠加
│   ├── InnerShadow.kt / CombinedBackdrop.kt / DampedDragAnimation.kt
└── io/github/zpan2327/hyperhand/glass/
    ├── HyperGlassBarView.kt             AbstractComposeView 桥接，API 对齐原 Java GlassBar
    └── ViewBackdrop.kt                  自定义 Backdrop：把页面 View 画进位图给玻璃采样
```

`MainActivity` 里就是一个普通子 View：

```java
nav = new HyperGlassBarView(this);
nav.setAccentColor(pal.primary);
nav.setOnTabSelected(index -> selectTab(index, true));
nav.setBackdropSource(contentHost);           // 玻璃采样的页面
root.addView(nav, navLp);                     // 底对齐 + 左右 20dp + 底 12dp
```

页面滚动时宿主必须通知它：`onScrollChange` → `nav.onContentScrolled()`（内部合并到一帧一次）。

## 踩过的坑

### 1. 直接搬 AAR 进 javac 构建 → `NoClassDefFoundError: customview.R$id`

`AbstractComposeView` 依赖 `androidx.customview` 的 R 资源，手工 `aapt2 + javac + d8` 的构建链
不会合并依赖 AAR 的资源，运行时找不到 `R$id`。同理 `ComponentActivity` 也需要
`androidx.activity` 的资源和 `lifecycle` 初始化。

**结论**：这条路走不通，构建迁到 **AGP 9.4.1 + Gradle 9.7.1**（`module/build.gradle.kts`），
`module/build.sh` / `build.ps1` 保留成薄壳，产物路径仍是 `module/out/HyperHand.apk`。

### 2. 宿主 Activity 不是 `ComponentActivity` → Compose 起不来

`AbstractComposeView` 需要一个 `ViewTreeLifecycleOwner` / `ViewTreeSavedStateRegistryOwner`，
`MainActivity` 改成继承 `ComponentActivity` 即可（模块其它逻辑不受影响）。

### 3. 关于页崩溃：`MiuixBg` 的 `RuntimeShader` 撞上软件画布

`ViewBackdrop` 把页面重画到一个 `Bitmap` 上，那是**软件 Canvas**；页面里任何依赖
`RuntimeShader` / `RenderEffect` 的自绘 View 都会抛。给 `MiuixBg` 加
`if (gpu != null && canvas.isHardwareAccelerated())` 守卫，同时采样失败只丢这一帧的玻璃
（`try/catch` + 一次性日志），绝不让整个界面挂掉。

### 4. 玻璃里出现「胶囊上方那一行」的折射

采样几何错了：`Backdrop.drawBackdrop()` 的 `size` 是「(胶囊 + 2×padding) / downscaleFactor」的
**采样层**尺寸，而绘制坐标原点在 **胶囊左上角**（miuix 在调用前 `translate(padding / ds)`），
层在负方向。按「层左上角」算平移会整体偏一个 padding（40dp ≈ 110px）。

**改法**（`ViewBackdrop.kt`）：反推 padding，截整层，平移相对 capsule 算，位图 1:1 绘制不缩放。

> 判定标准：把一条横贯全宽的边界（滑杆轨道、卡片边缘）放到胶囊后面，量它在胶囊内外的 y 中心差；
> 正常只差几个像素（边缘折射带压缩），差 100px 就是这条。

### 5. 玻璃只采样到胶囊中间一条，右半边更透

同一个 `size` 的另一种错用：把 434 当成胶囊宽度（实际胶囊 649），于是右侧近 200px 没有任何采样，
只剩 40% 白蒙层。和第 4 条一起修。

### 6. 滚动时玻璃不实时刷新

`View#invalidate()` 只让宿主 RenderNode 变脏，Compose 的 `AndroidComposeView` 还是干净的，
`drawBackdrop` 的绘制节点不会重跑。给组件加一个普通 `Int` 参数 `redrawSignal`，在
`effects { }` / `layerBlock { }` 里读一下——值变了，lambda 必须重建，绘制节点才会更新。
（不能传 `State`：只捕获稳定值的 lambda 会被 Compose 记忆化。）

### 7. 先拖一下底栏、再滚页面，选中项（指示器）定格

指示器采样的是 `CombinedBackdrop(页面背板, tabsBackdrop)`，而 `tabsBackdrop` 由
`Modifier.layerBackdrop()` 录下来，**只有录制源节点重画时才会重新 `recordLayer()`**。
拖动时那一行一直在动所以是新的；松手动画收敛后就静了。

**改法**：把 `redrawSignal` 同时接给**隐藏图标行**（录制源）和指示器，三处都要接。

### 8. 按下时圆角冒黑楔形

折射 + 色散在圆角处会采到采样层之外。`LayerBackdrop` 背后是整窗内容，越界也有东西；
`ViewBackdrop` 只有本层，越界即透明（黑）。`effects { padding = maxOf(padding, 40.dp.toPx()) }`，
容器和指示器两层都补。

### 9. 胶囊顶边被削平 / 位置偏高 / 底栏被加宽

- **顶边被削平**：`ComposeView` 按自身 bounds 裁剪，按下放大 + 10dp 投影溢出会被切。
  `Modifier.padding(top = 14.dp)` 留余量（只留上方）。
- **位置偏高**：组件自己会叠 `navigationBars` inset，宿主已经用 margin 让开一次 → 传
  `bottomPadding = 7.dp`（对齐原 `GlassBar` 的 78dp 视野）。
- **宽度**：除了把 `backdrop` 类型从 `LayerBackdrop?` 放宽到 `Backdrop?`（`ViewBackdrop` 需要），
  组件内部的排版参数一个都没动。实测 649px 宽（`76dp × 3 + 8dp` 上限内），与原版一致。

### 10. 很卡

第一版 `ViewBackdrop` 把整屏 1080×2280 全分辨率重画，每帧一次，模拟器上几乎不可用。
改成：只截「采样层」区域、按 `1/downscaleFactor` 采样、同一帧内容器与指示器共享一张位图，
并在下一帧开头失效。滚动 jank 从 88% 回到 85.7%（模拟器 SwiftShader 本身只有 ~10fps，真机 GPU 不背这个锅）。

## 参数

与上游逐行一致，没有为了「看起来更淡」而调倍率：

| 位置 | 值 |
| --- | --- |
| 玻璃体 | `vibrancy()` → `blur(4dp)` → `lens(24dp, 24dp)` |
| 底色 | `surfaceContainer @ 0.4` |
| 指示器按压 | `lens(10dp·p, 14dp·p, depthEffect, chromaticAberration = 0.5)` |
| 边缘高光 | `alpha = 0.75`，随重力旋转 |

`refractionScale` 这个倍率参数已经删掉了：曾经因为「叠在纯色列表页上文字被撕」把它调到 0.4，
后来证明根因是第 4、5 条的几何错误，修好后原参数就是对的。

## 已知限制

- 折射需要 **AGSL（Android 13+）**；更低版本自动降级成模糊 + 蒙层，不崩。
- `ViewBackdrop` 每帧把页面重画一次到 Bitmap，页面越复杂越贵；本模块的页面都是 `ScrollView`，
  实测可接受。若将来引入大量自绘/视频控件，需要改成「只重画脏区」或换 `PixelCopy`。
- 玻璃只采样 `contentHost`（页面内容），顶栏与底栏互相之间不采样。
